# Read-only paged-attention physical evidence

This package admits an immutable, non-circular, exact-SM120 qualification
campaign for the post-write paged-attention candidate. It binds the full-QKV
input activation and row width, fallback, compiled CUBIN, per-token dispatch
canary, cache immutability, numeric oracles, tools, SASS, sanitizers, and seals.

The admitted and qualified values remain opaque and carry neither manifest,
deployment, promotion, nor runtime-dispatch authority.

The `policy_authority` text is descriptive only. Policy admission is valid
only when its canonical SHA-256 equals an independently governed expected
digest supplied out of band; evidence then binds that exact policy digest.
