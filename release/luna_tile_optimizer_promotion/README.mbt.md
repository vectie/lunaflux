# LunaTile optimizer promotion

This offline release package closes the authority chain for the generic
parallel-SIMT candidate and the exact-sm120 BF16 `m16n16k16` tensor-core
candidate without placing qualification work in production execution.

SIMT physical admission consumes the immutable campaign result, its complete
`FILES.sha256` bytes and the publication-time manifest digest. It rebinds the
exact serial and parallel canonical/source identities, deterministic first and
second CUBINs, clean stderr files, physical outcome and explicitly absent
authority. Tensor-core promotion consumes the existing opaque admitted
physical-evidence type and does not duplicate its evidence parser.

Every candidate then needs at least three bounded paired measurements. Every
pair must beat its exact fallback and the aggregate must exceed the declared
minimum win. SIMT compares against the serial CUDA oracle; tensor core compares
against the exact admitted SIMT fallback. Physical and benchmark evidence stay
inert until the exact canonical promotion record is authenticated by the
existing opaque external-approval capability.

The approved output is a content-addressed, manifest-bindable catalog entry
with exact module, source, entry point, launch, fallback, deployment and epoch
identity. Startup selection is exact-or-baseline: absence retains baseline;
a present stale or substituted entry fails closed.

No production model operation currently has the generic fixture's exact tensor
and operand ABI. Consequently this package does not create a kernel-catalog
`OperationId` or runtime launch binding. The remaining seam is an authenticated
model-operation specializer that maps one real plan operation's exact operands,
shape and numerical contract to this approved artifact. Until such a truthful
mapping exists, startup can retain the approved catalog identity but production
dispatch remains on the existing baseline.
