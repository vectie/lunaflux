# Mistral weight admission

This package owns the exact Hugging Face Mistral tensor-name translation into
the existing dense semantic `TensorRef` order. It rejects incomplete, extra,
mis-shaped, foreign-content, foreign-plan, and sliding-window-replayed
manifests before materialization authority exists.

Deployment files use the generic canonical numeric-safetensors vocabulary.
The facade rebuilds the exact Mistral plan, delegates full artifact, schema,
range, payload, layout, second-pass, and cleanup ownership to
`numeric_weight_file`, and returns an inert `MistralWeightFileInspection` for
the shared dense numeric worker. This package itself owns no scheduler, KV
policy, executor, CLI, readiness, or physical-validation authority.

The wider runtime route is now implemented: authenticated launch recipe
`DenseMistralBf16PagedAotV7` selects the strict Mistral descriptor, verifies the
route-manifest identity, constructs the existing numeric BF16 worker plan, and
uses the same singular dense worker/service owner as the legacy Llama BF16
route. The family branch therefore ends before scheduler and device execution,
as required. This is source and local-test readiness only; no Mistral GPU
execution, physical numerical agreement, accuracy, memory, performance, or
production-promotion evidence is claimed.
