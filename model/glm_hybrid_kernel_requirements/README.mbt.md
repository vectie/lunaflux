# GLM hybrid kernel requirements

This package derives a bounded, immutable, first-use-ordered semantic/AOT
requirement set from a validated GLM hybrid execution plan. Generic advanced
decoder AOT vocabulary is reused for identical mHC, MoE, MTP, embedding, norm,
and projection capabilities; GLM-specific DSA, KDA, dense-SwiGLU, and vision
semantics remain distinct.

The digest binds the authenticated model identity, exact hybrid plan digest,
semantic geometry, and AOT capability order. Projection to current generic
kernel IDs is lossless and stops at the first unsupported operation. This
package does not select, qualify, load, or claim any artifact.
