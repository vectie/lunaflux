# Advanced-decoder candidate evidence

This family-neutral startup adapter converts typed advanced-decoder CUDA source
candidates into structural coverage inputs. It owns no model profile, artifact
admission, loader, launch, qualification, or execution authority.
Foundation, replicated Query-A block-FP8 projection, projection, rotary,
routing, deterministic compressed-index,
window/compressed join, borrowed compressed-K/V preparation, selected sparse
attention, attention-output inverse RoPE, and all four versioned mHC phase
candidates have separate typed adapters and remain non-bindable evidence.
