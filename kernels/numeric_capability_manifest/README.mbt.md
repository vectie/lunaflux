# FP8 kernel capability manifest

This package binds one complete model numeric-schema digest to an exact
observed device numeric capability, resolved kernel catalog, launch contracts,
and one already digest-admitted artifact bundle. Each finite-E4M3 W8A8
operation has one immutable per-profile view naming its operation-execution
digest, exact FP8 weight-storage and scalar-F32 scale-schema identities, and
exact AOT entry point. Module bytes are owned once by the aggregate, never
copied into per-operation records. The scale bindings are inert launch-planning
evidence for a future physical backend; the legacy launch ABI is not widened.

Admission rejects incomplete FP8 execution contracts, unsupported or mismatched
targets, vendor/BF16 fallback, missing/duplicate/reordered claims, foreign entry
points, and artifact drift. The result is inert startup evidence. It does not
load a module, open a device, execute a kernel, or claim physical correctness.
